# GridForge v11.11 — Continuation Guide

## Implemented

- Worksheet tab reordering and tab-color presets with GridForge JSON and XLSX persistence.
- Hide/unhide selected rows and columns with GridForge JSON and XLSX persistence.
- Find All across visible worksheets with clickable sheet/cell results.
- Custom multi-level sorting with macro replay support.
- Date and text-length validation, including native XLSX validation metadata.

## Useful next gaps

- Workbook-wide Replace All with a single cross-sheet undo transaction.
- Cross-worksheet formula references and broader chart/pivot support.
- Worksheet protection with clear, Excel-compatible limits.
- Richer sheet move/copy placement.
- Custom-formula validation and more native Excel validation types.

Windows desktop, installer and UI tests were not run. Installer metadata is set to 11.11.0 for a future Windows build.

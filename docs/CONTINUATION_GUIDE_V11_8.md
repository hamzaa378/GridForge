# GridForge v11.8 — Continuation Guide

## Implemented in v11.8

- Dynamic in-sheet range dropdown sources.
- Whole/decimal validation with eight comparison operators.
- Input titles/messages and Stop, Warning, or Information invalid-entry behavior.
- JSON and supported XLSX persistence for the added validation settings.

## Useful next gaps

- Date and text-length validation.
- Cross-sheet and defined-name list sources.
- Validation prompts and error alerts in the macro-preserving XLSM patcher.
- Make rule edits part of workbook undo/redo.
- Protect worksheets and workbook structure with cell-level lock settings.

Windows desktop/installer/UI tests were intentionally not run for this source release. Installer metadata is set to 11.8.0 for a future build.

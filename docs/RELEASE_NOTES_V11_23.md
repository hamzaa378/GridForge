# GridForge 11.23.0 Release Notes

## Compatibility improvements

- Extended XLOOKUP to return aligned rectangular row or column results through the workbook spill engine; expanded TIMEVALUE to parse AM/PM and DATEVALUE to parse year-first or English month-name dates; corrected ISBLANK handling for formulas returning empty text, and corrected COUNTA to include such formulas and error values, and COUNT to ignore error cells in references.
- Refined TRIM to remove and collapse ordinary ASCII spaces while preserving tabs, newlines, and non-breaking spaces. NUMBERVALUE now handles ordinary spaces, first-character separators, invalid separator combinations, repeated trailing percent signs, and empty text more closely to Excel. DATEDIF now calculates its supported Y/M/D/MD/YM/YD units with improved year-boundary handling; MD follows intended remainder behavior rather than Excel’s documented known inaccuracies. XNPV validates numeric equal-length cash-flow/date ranges, mixed-sign flows, Excel date bounds and truncated serials; zero-rate `#NUM!` follows the saved Excel 16.0 differential fixture, not an explicit Microsoft-documented constraint.
- Normalized date-formatted numeric literals from Excel 1904-system workbooks into GridForge’s 1900 serial system without shifting ordinary numeric cells or formulas. Supported Excel date number format codes now persist through XLSX import/export, and a supported date/time token subset is rendered in the grid. Locale-dependent built-in formats are approximate; unsupported tokens remain preserved but display as numeric values. Elapsed-time-only formats are excluded from 1904 shifting.
- Improved XLSX list validation import for direct local or workbook-level names on the same worksheet and for rules with multiple target areas; conditional-format import now retains all valid areas in a multi-area rule.
- Native ChartEx exports retain chart titles, data-label settings and legend placement. Histogram supports editable source data, bin count or bin width, underflow/overflow thresholds, data labels and series color; import restores its source range, supported settings and valid first-series RGB fill. Treemap/Sunburst export now retains multi-level category columns. Waterfall can mark its final point as a total, represented by ChartEx subtotal metadata and restored on import when the final subtotal index is supported. Chart editor controls appear for the matching chart type.
- Waterfall charts now support multiple selected total/subtotal points in the chart editor, preview, and native ChartEx subtotal metadata import/export. The legacy final-total option remains supported.
- `MATCH` now handles exact, ascending approximate (default), and descending approximate modes while checking sort direction. `XMATCH` and `XLOOKUP` now support forward, reverse, ascending-binary and descending-binary search; XLOOKUP also supports wildcard and next-smaller/next-larger match modes. Binary search verifies sort order and resolves duplicate exact keys by traversal direction.
- Page Setup now supports Excel Print Titles for repeated rows and columns. The ranges import/export through `_xlnm.Print_Titles`; browser printing repeats header rows on each page, while repeated columns are preserved for Excel export.
- XLSX combo-chart import/export now retains mixed column and line series, series order, and primary/secondary axis assignment for supported charts.
- Data Validation now preserves Excel input prompt visibility and text, error alert visibility and text, and Stop/Warning/Information styles. The validation editor exposes those settings and applies their corresponding entry behavior.
- `TEXTSPLIT` now accepts delimiter arrays, case-insensitive matching, custom padding for uneven rows, and ignore-empty behavior for both row and column delimiters. Excel default `#N/A` padding is not represented exactly.
- VLOOKUP and HLOOKUP now support ascending approximate lookup with order validation; their exact modes include Excel-style wildcard matching. LOOKUP approximate mode validates the ascending vector. TEXTBEFORE/TEXTAFTER now support instance direction, case mode, match-at-end, fallback, and empty-input/delimiter cases.
- View → Gridlines toggles worksheet gridline display while retaining explicitly formatted cell borders; the choice is stored in the GridForge workbook and XLSX worksheet view settings.
- Standard charts now offer Center, Inside End, Outside End, and Best Fit data-label positions, with supported DrawingML XLSX import/export. Best Fit is a preview approximation and ChartEx layouts do not retain position settings.
- Standard chart data labels can show values, category names, series names, and pie/doughnut percentages. Standard DrawingML preserves all four choices; ChartEx preserves value/category/series visibility, but has no percentage flag. Label positions round-trip only in standard DrawingML.
- Cell formatting now includes top/middle vertical alignment and increase/decrease indent controls. Indent metadata up to 250 levels and supported vertical alignment import/export through XLSX.
- Excel custom number-format codes are now preserved on XLSX import/export, can be edited from the formatting toolbar, and render a bounded common subset of numeric formats. Unsupported conditions/tokens remain preserved and fall back to the regular number display.
- Border presets now include top, left and right edges alongside all-edge and bottom-edge borders, with supported XLSX import/export.
- Dynamic-array formulas now have expanded Excel-style `FILTER` row/column behavior, multi-key `SORTBY`, column sorting with `SORT`, omitted-argument and empty-result handling for `TAKE`/`DROP`, case-insensitive `UNIQUE`, and row/column-major `TOCOL`/`TOROW` scans.
- Standard chart series names that match worksheet headers are exported as references to those header cells, so Excel can update the chart legend when a header changes.
- The cell context menu can insert, edit, and remove worksheet hyperlinks. Imported and created links display with hyperlink styling and open supported external HTTP/HTTPS/mailto targets in a new tab, or select cell ranges on visible worksheets. Direct `HYPERLINK` formulas also open supported destinations; nested formula links, defined-name navigation, and hidden-sheet navigation remain unsupported.
- `SHEET()` and `SHEETS()` now use workbook worksheet order and count for supported one-sheet references. `AGGREGATE` covers function numbers 1–19, adding MEDIAN, MODE.SNGL, and inclusive/exclusive percentile and quartile calculations. Reference-form options can ignore manually hidden rows, errors, and nested SUBTOTAL/AGGREGATE formulas, and row visibility changes refresh affected formulas; computed-array inputs and filter-hidden rows remain limited.

## Excel-style feature availability

- Added Data ribbon entry points for Power Query, the Data Model, Power Pivot/DAX, OLAP, native Excel Timelines, and PivotChart field buttons.
- Selecting an unavailable or partially supported feature opens a clear explanation with the nearest supported GridForge workflow.
- Added Help → Feature availability, a clickable status catalog for major compatibility areas: PivotTables/PivotCharts, specialized charts, formulas, data connections, and model features.
- Updated the README with complete runtime, development, and Windows installer dependencies and commands.
- Expanded value sorting from one PivotTable axis field to independent value sorts on multiple row and column fields. Each field stores its own selected Values calculation and native XLSX AutoSort scope.
- Added support for multiple native Top/Bottom PivotTable value filters, with one filter per selected row or column field. Imported filters round-trip and run in stable axis order: row fields parent-to-child, then column fields. The dialog provides controls to add, edit, and remove each filter.
- Preserved an explicit “no visible items” selection in imported PivotFields through summary generation and XLSX export. Slicer buttons now toggle individual values both on and off during an active multi-select filter, and connected summaries retain an empty selection.
- Preserved manual item ordering from imported PivotTables through GridForge summary refresh and native XLSX export. Added an item list with Move Up/Move Down controls for fields set to Manual; manually grouped fields expose their group captions first, followed by ungrouped items. Manual ordering now uses visible group captions for manual groups and visible bins or labels for numeric and date groups. Changing grouping options reconciles the ordered list; reopening an existing summary after source data changes or editing its source range retains existing item order while adding or removing categories.
- Preserved and exposed custom grand total, Values field, and compact row-header captions from imported Excel PivotTables; captions can be edited and are written back to native PivotTable XML.
- Expanded native PivotTable import to resolve workbook-scoped defined names that reference direct ranges on a worksheet; formula-based and external-workbook names remain out of scope.
- Updated desktop app and installer version metadata to 11.23.0.

## Compatibility limits

The new notices are documentation of current code capability; they do not implement Power Query M, the Excel Data Model, Power Pivot/DAX, OLAP, Excel Timeline objects, or full Excel PivotChart editing. GridForge remains an Excel-style alternative with its own grid and calculation engine. See [the feature matrix](FEATURE_VERIFICATION_V11_23.md) and [Excel compatibility audit](EXCEL_COMPATIBILITY_AUDIT.md).

## Verification scope

The TypeScript no-emit check passed after the latest formula-context, hyperlink UI, and chart-label changes. Automated tests, Windows tests, application launch, live UI test, and Excel GUI validation were not run for this update.

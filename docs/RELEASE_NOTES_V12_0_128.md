# GridForge v12.0.128 — Manual page breaks

Page Layout can add or remove a row or column break before the active row or column, clear all manual breaks, and display manual boundaries in Page Break Preview. XLSX import/export preserves native worksheet row and column break records. The browser print view applies manual row breaks. Column breaks are saved and previewed but browser pagination does not apply them.

Verification is limited to the TypeScript check, production build, and release packaging. No automated tests, desktop launch, live UI, or Excel GUI checks are performed.

Recent changes: line, scatter, radar, and combo-line chart points can have individual colors. The chart editor now displays up to 64 point color controls; serialized/imported chart point palettes remain bounded at 10,000 points. The editor and SVG preview expose them; XLSX stores colors on native marker records and preserves the series stroke; ODS uses per-point styles. Distinct, complete per-series point-color arrays are validated and round-trip through XLSX and ODS, including ODS after GridForge-only sheet metadata is removed. The chart editor retains imported arrays when editing other options without changing chart type or source range; it does not yet provide direct per-series point-color editing. Cross-sheet scalar/range formulas, quoted sheet names, rename/delete invalidation, and cycle detection are implemented; XLSX and ODS formulas recalculate when a referenced sheet changes. Focused regression tests cover these paths. Remaining compatibility work should be grounded in the feature matrix/audit and tested with code-only fixtures. GridForge is not feature-equivalent to Excel or LibreOffice; avoid claiming full parity.

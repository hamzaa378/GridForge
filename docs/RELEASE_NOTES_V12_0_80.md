# GridForge v12.0.80

## Cloud folder navigation

- Browse nested folders and XLSX/JSON workbooks in OneDrive, Google Drive, Dropbox, and Box.
- Use breadcrumbs to return to a parent folder.
- Save a new workbook copy in the folder currently open; saving changes to an already opened workbook keeps updating that file.

## Verification

- TypeScript static validation and release compilation are performed with `-SkipTests`.
- No app launch, live UI, Windows runtime, or provider account tests were run.

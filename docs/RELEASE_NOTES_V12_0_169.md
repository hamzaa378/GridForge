# v12.0.169 — ODS chart categories and series markers

ODS chart import/export now preserves supported category-axis tick intervals and each series' explicit marker visibility for native ODF charts. This extends v12.0.168's support for category-axis rotation/reversal and base-10 logarithmic value axes. More complex marker shapes, axis number formats, secondary-axis combo charts, specialized chart classes, external chart editing, and live source-data linkage remain incomplete. No automated tests or LibreOffice UI round-trip were run.

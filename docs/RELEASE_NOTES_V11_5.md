# GridForge 11.5.0 Release Notes

## Formula ribbon

- Added searchable function insertion with descriptions, examples and category filters.
- Added compact ribbon menus for logical, text, date/time, lookup/reference, math/engineering, statistical and financial functions.
- Expanded AutoSum to insert SUM, AVERAGE, COUNT, MAX or MIN for a selected range or the numeric run above the active cell.

## Formula auditing

- Trace Precedents and Trace Dependents highlight the direct cells in the workbook dependency graph. Remove clears the highlights.
- Show Formulas toggles formula text in worksheet cells.
- Evaluate opens an inspection view of the expression tree, referenced values and current result.

GridForge remains a standalone spreadsheet with its own worksheet UI and calculation engine. Microsoft Excel is not embedded or required. This release does not provide full Excel feature parity.

# GridForge v12.0.140 — Border formatting and export

- Cell borders now support solid, dashed, dotted, and double lines with a selectable color.
- The chosen border appearance renders in the worksheet and is preserved for supported uniform all-edge or single-edge borders in XLSX and ODS import/export.
- Mixed per-edge border colors and styles, diagonal borders, border weights beyond the supported line mapping, and advanced conditional table-border behavior remain limited.
- TypeScript and Windows installer builds completed with automated test phases skipped; release archives were generated. No application launch, live UI, Excel GUI, or LibreOffice GUI checks were run.

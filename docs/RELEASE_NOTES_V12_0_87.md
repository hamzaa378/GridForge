# GridForge v12.0.87

## Reverse category order

- Category-based column, bar, line, area, stacked, 100% stacked, combo and radar charts can reverse category order.
- The local SVG renderer reverses labels and point values together.
- XLSX standard chart category-axis orientation is imported and exported. The option is hidden for scatter and specialized chart types.

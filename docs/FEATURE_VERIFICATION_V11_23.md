# GridForge v11.23 Feature Matrix

| Area | Status exposed in the app | Current implementation and limitation |
|---|---|---|
| Excel feature availability | Available | Help → Feature availability lists major unsupported and partial Excel features, gives a status, explanation, and nearest GridForge workflow. Relevant Data ribbon buttons open the matching notice. |
| Power Query | Partial | Worksheet cleanup/query steps and public HTTPS CSV/JSON refresh are available. Power Query M, its editor, built-in connectors, credential management, and Excel connection objects are absent. |
| Data Model | Not available | No tabular model, model relationships, model storage, or Excel Data Model refresh. Pivot Summary sources are worksheet ranges or tables. |
| Power Pivot / DAX | Not available | No Power Pivot model editor or DAX measures/calculated columns. GridForge formulas and Pivot Summary aggregations are worksheet-local tools. |
| OLAP | Not available | No OLAP cube, Analysis Services, or semantic model connections. |
| Timelines | Not available | Native Excel Timeline objects are absent. GridForge supports date filters and on-sheet slicer cards for supported ungrouped Pivot Summary fields. |
| PivotCharts | Partial | Supported standard charts linked to Pivot Summaries export with PivotTable linkage metadata. Editing is through the regular chart editor; Excel field buttons and the full PivotChart pane are not implemented or verified. |
| Top/Bottom value filters | Available for the supported subset | Import, summary calculation, and XLSX export support one filter per selected row or column field; the dialog can add, edit, and remove multiple filters with independent field, measure, direction, and count settings. Filters are applied in selected axis order (row fields parent-to-child, then column fields). |
| Nested value sorting | Available for the supported subset | Each selected row or column field may sort by its own Values calculation in ascending or descending order. Import/export preserves per-field OOXML AutoSort scope. Excel GUI acceptance remains unverified. |
| Manual Pivot item ordering | Available for the supported subset | Imported manual field order is preserved in summary refresh and native XLSX export. In the Pivot Summary dialog, choose “Manual (starts in source order)” to reorder items with Move Up/Move Down controls. Manual groups expose their captions first, followed by ungrouped values; date and numeric groups expose the displayed grouped labels. Changing grouping modes reconciles the order list to the new labels. Reopening a Pivot after source data changes or changing its source range reconciles categories, retaining the relative order of existing entries and appending new items in source order. |
| Pivot captions | Available for the supported subset | Custom Excel `grandTotalCaption`, `dataCaption`, and `rowHeaderCaption` values import from native PivotTable XML, remain editable in the Pivot Summary dialog, appear on grand totals, the Values field label, or the compact-layout row heading, and export back to PivotTable XML. Excel GUI round-trip has not been verified. |
| Pivot source names | Available for the supported subset | Import resolves workbook-scoped names that directly reference a worksheet range, as well as supported local names and table names. Formula-based or external references are not resolved. |
| Pivot item selections | Available for the supported subset | XLSX import/export preserves all-visible, selected-item, and explicitly no-visible-item states. Slicers toggle items on and off while a filter is active; clearing the filter restores all items. |
| Pivot field capacity | Improved | Rows, Columns, report filters, axis filters/groups/sorting, and Values calculations are bounded by source width, destination worksheet columns, and output limits rather than a fixed eight-field cap. High-field-count workflows are code-checked and built, but have not been validated in Excel. |
| Specialized charts | Partial | Histogram now uses native ChartEx export/import with an editable source range, bin count or bin width, underflow/overflow thresholds, title, data-label setting, and configured series color for one numeric series; multi-level Treemap/Sunburst category levels are retained in ChartEx. Waterfall allows multiple total/subtotal points in the editor and round-trips supported subtotal indexes in ChartEx. ChartEx legend placement and supported first-series RGB fill import/export. Advanced style and hierarchy round-tripping is limited, and Excel GUI acceptance has not been verified. |
| Formula compatibility | Partial | Hundreds of formula names are registered, but that is not a claim of exact Excel semantics. `SHEET()`/`SHEETS()` now resolve workbook worksheet order/count and references to one worksheet; 3D references and defined-name arguments remain unsupported. `AGGREGATE` supports function numbers 1–19 and, for direct reference/range arguments, options to ignore manually hidden rows, errors, and nested SUBTOTAL/AGGREGATE formulas; hide/unhide refreshes dependent results. `FILTER` accepts matching row or column include vectors and an array-valued if-empty result; `SORT` can sort by row or column; `SORTBY` supports multiple stable sort keys with independent directions; `UNIQUE` compares text case-insensitively and errors for an empty exactly-once result. `TAKE`/`DROP` handle omitted row/column arguments and return `#CALC!` for zero-sized/empty results. `TOCOL`/`TOROW` support blank filtering and row/column-major scan order; error-ignoring is limited by formula argument error propagation. Other computed-array expressions and filter-hidden row behavior remain limited. XLOOKUP supports aligned row/column return arrays, exact/wildcard/approximate modes, reverse search, and ascending/descending binary search. XMATCH supports exact/wildcard/approximate modes and forward/reverse/binary searches; MATCH supports exact and sorted approximate modes with the Excel default of ascending approximate. Binary lookup validates sort direction. TIMEVALUE accepts AM/PM; DATEVALUE accepts unambiguous ISO/year-first and English month-name dates; ISBLANK distinguishes formula-empty-text from an empty cell; COUNTA includes formula-empty-text and errors; COUNT ignores errors in referenced cells; TRIM follows ASCII-space-only behavior; NUMBERVALUE handles ordinary spaces, separator validation, and repeated trailing percent signs; DATEDIF supports six units with intended month/day remainder behavior. XNPV validates equal numeric ranges, dates, cash-flow signs, and uses truncation for date serials; zero-rate `#NUM!` follows saved Excel 16.0 comparison evidence rather than a documented Microsoft constraint. Excel documents known inaccurate MD cases, so exact DATEDIF parity is not claimed. Other spill, service-dependent, locale/date, precision and error-coercion gaps remain. |
| Print Titles | Partial | Page Setup stores whole-row and whole-column repeat ranges and imports/exports supported local `_xlnm.Print_Titles` definitions. Browser printing repeats selected rows at the top of each page; repeated columns are preserved in XLSX for Excel but not rendered by the browser print view. |
| Combo charts | Partial | XLSX import/export preserves mixed column and line series, their series order, and primary/secondary axis assignment for the supported chart subset. Other Excel chart groups and axis combinations may be normalized or omitted. |
| Chart data labels | Partial | Value, category, series, and pie/doughnut percentage content plus Center, Inside End, Outside End, and Best Fit positions are editable for standard charts. Standard DrawingML preserves content and position; ChartEx preserves value/category/series visibility but has no percentage flag and does not preserve position. Best Fit is approximated as Outside End in preview. |
| Validation alerts | Improved for supported rules | Validation prompt titles/messages, visibility flags, error messages/titles, and Stop/Warning/Information styles import and export. The editor exposes these options; warning prompts for confirmation, information displays a message and permits the value, and disabled error alerts permit invalid entries. |
| TEXTSPLIT | Partial | Supports multiple row/column delimiters, ignore-empty behavior, case-insensitive matching and custom padding for ragged results. Excel default `#N/A` padding and some locale-specific case rules are not represented exactly. |
| Vertical/horizontal lookup | Partial | VLOOKUP and HLOOKUP now support exact lookup plus ascending approximate matching with sort validation; exact mode handles case-insensitive wildcard matching. LOOKUP now validates ascending approximate vectors. Excel coercion details remain incompletely compared. |
| TEXTBEFORE / TEXTAFTER | Partial | Supports positive or negative delimiter instances, match case, end-of-text matching, not-found fallback, empty delimiter, and empty text behavior. Locale-sensitive matching and full Excel error/coercion behavior remain incompletely compared. |
| Worksheet gridline display | Available | View → Gridlines toggles visible worksheet gridlines and preserves the setting in GridForge workbooks and XLSX. User-applied cell borders remain visible. |
| Cell alignment | Improved | The formatting toolbar now supports vertical top/middle alignment and Excel-style increase/decrease indent. Indentation up to 250 levels and supported vertical alignment round-trip through XLSX. Distributed/justified alignment, orientation/rotation, and shrink-to-fit are not implemented. |
| Cell borders | Improved for single-edge presets | All, bottom, top, left, and right thin borders can be applied and preserved through XLSX. Mixed edge styles, edge colors, and other line styles are not represented in the cell-style model. |
| Custom number formats | Improved for common codes | Custom format codes are retained on XLSX import/export and can be entered in the toolbar. Grid rendering supports common placeholders, decimal/group separators, percent scaling, quoted literals, color tags, numeric sections, scientific notation, and the fourth section's `@` text substitution. Conditional sections, fractions, locale-specific separators and many Excel tokens are not rendered equivalently. |
| Conditional formatting | Improved | Numeric rules now include inclusive comparisons, inequality, and between/not-between in addition to greater/less/equal. Two-color and optional three-color scales interpolate through a 50th-percentile midpoint and round-trip through native XLSX rules. Excel's full `cfvo` threshold types, icon sets and formula-based rules remain incomplete. |
| Worksheet hyperlinks | Partial | Insert/Edit/Remove hyperlink actions are available in the cell context menu. Single-cell HTTP, HTTPS, mailto, and internal-location links import/export with supported display text and tooltips. Links render with hyperlink styling; clicking opens safe external targets in a new tab or selects an in-workbook cell range on a visible worksheet. Direct `HYPERLINK` formulas with supported target schemes are clickable; nested formula links and defined-name navigation are not implemented. |
| XLSX date formats and 1904 date system | Improved for supported cells | Import/export preserves supported Excel date number format codes and renders a supported date/time token subset. Import converts date-formatted numeric literals from the 1904 system to GridForge’s 1900 serial system; ordinary numeric cells and formulas are not shifted. Locale-dependent built-in formats are approximate; unsupported format tokens remain preserved for re-export but fall back to numeric display. Date-format detection is heuristic; elapsed-time-only formats are excluded from 1904 conversion. |
| XLSX validation and formatting ranges | Improved for the supported subset | List validation imports direct same-sheet defined names and multiple target areas. Conditional-formatting rules also apply to each valid area in a multi-area `sqref`. Ambiguous/formula/external names and unsupported conditional-format rule types remain unsupported. |
| External refresh | Partial / unavailable by source | Public HTTPS CSV/JSON query refresh is supported subject to browser CORS and request limits. Authenticated Excel connections, Power Query connections, OLAP refresh and Data Model refresh are absent. |
| Remaining broad Excel gaps | Not exhaustive | Full native PivotTable authoring/editing, complete Excel chart editing, VBA execution inside GridForge, Power Query M, Data Model, DAX, OLAP, coauthoring/cloud services, and comprehensive Excel compatibility remain out of scope or incomplete. |

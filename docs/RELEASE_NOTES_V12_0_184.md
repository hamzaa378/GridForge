# GridForge v12.0.184 — Formatted print output

Worksheet printing and printable HTML now render supported cell styles and formatted display values: custom font family and size, bold/italic/underline/strike, font and fill colors, horizontal and vertical alignment, wrapping, indentation, border edges, and number/date formats. Header rows retain the source cell styling.

Browser pagination, merged-cell layout, diagonal-border precision, and conditional-format appearance remain limited.

Verification for this source release: TypeScript check only. No automated tests, Windows tests, live UI, printer, or Calc/Excel GUI round-trip were run.

# GridForge v12.0.199 — Conditional-formatting fidelity

Conditional formatting now includes native XLSX icon sets and custom two- and three-color scales. The rule dialog exposes scale threshold types for minimum, maximum, number, percent, percentile, and formula stops, lets users choose per-icon percent, percentile, number, or formula cutoffs, and lists existing rules with a per-rule remove action. Icon sets preserve threshold type/value, reverse ordering, and show-values settings; newly created rules receive a priority after existing rules so imported rule ordering remains stable; their previews use distinct traffic-light, arrow, rating, and symbol glyphs. Color scales now interpolate between configured stops in the calculation/rendering model. Numeric, percentage, percentile, minimum, maximum, and formula thresholds are evaluated per rule; Excel XLSX color-scale thresholds and colors round-trip as native conditional-formatting XML. Invalid threshold counts and values are rejected during workbook validation.

ODS now preserves color-scale minimum/maximum, numeric, percent, percentile, and formula stops through Calc extensions. Icon sets and priority metadata remain GridForge-only in ODS; native Calc icon-set interchange, data-bar formula thresholds, blank-cell coverage, and full precedence remain incomplete. Scale and icon rendering are GridForge approximations; no live UI or LibreOffice GUI testing was run.

Verification: 1,085 code-only tests, TypeScript check/build, ODS and XLSX round-trips, four core regression stages, a 10,000-formula benchmark, and a 10,000-cell stress/undo benchmark pass. Static formula probes agree on 136/136 deterministic scalar cases; no live UI or LibreOffice GUI testing was run.

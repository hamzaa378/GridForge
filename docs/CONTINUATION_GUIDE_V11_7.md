# GridForge v11.7 — Continuation Guide

## Implemented in v11.7

- Worksheet Data Validation for inline dropdown lists, whole numbers and decimals.
- Selection-scoped rules with blank handling; invalid manual edits are rejected with a cell-specific message.
- Rule persistence in GridForge JSON and supported XLSX validation records.
- Data ribbon entry point and edit/clear workflow.

## Useful next feature gaps

- Range-sourced dropdowns and custom-formula validation.
- Date and text-length validation.
- Validation input prompts and configurable stop/warning/information error alerts.
- Copy/fill behavior for validation ranges and more complete XLSX/XLSM round-trip coverage.

Windows desktop and installer tests were intentionally not run for this release. The installer version metadata is set to 11.7.0 for a future build.

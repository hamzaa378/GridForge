# GridForge v12.0.78

## Clipboard operation limits

- Copy, cut, and paste now stop before materializing more than 50,000 cells at a time.
- Oversized selections show a direct message; the grid remains usable.

## Verification

- Static TypeScript validation and installer/portable compilation are used for this release.
- No automated tests, Windows runtime tests, app launch, live UI, or Excel GUI tests were run.

# GridForge 12.0.31

Added Excel-style keyboard selection shortcuts: Shift+Space selects the active row, Ctrl+Space selects the active column, and Ctrl+Shift+Space selects the entire worksheet. These selections use the existing range-selection behavior and therefore work with range actions already supported by GridForge.

Verification was limited to static TypeScript checking and production packaging with the test phase skipped. No tests, app launch, live UI, Windows runtime, or Excel GUI checks were run.

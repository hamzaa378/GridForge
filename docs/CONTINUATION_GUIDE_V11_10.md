# GridForge v11.10 — Continuation Guide

> Continued in v11.11. See [the v11.11 guide](CONTINUATION_GUIDE_V11_11.md).

## Implemented

- Worksheet hide/unhide controls and persistence in GridForge JSON/XLSX.
- Text to Columns with preview and common delimiters.
- Dynamic worksheet range validation lists, numeric criteria, prompts and alerts.

## Useful next gaps

- Protect/unprotect worksheets and workbook structure.
- Move/copy/reorder sheets and tab colors.
- PivotTables and richer chart filters.
- Date, text-length and custom-formula validation.
- Preserve more workbook structure in macro-enabled XLSM updates.

Windows desktop, installer and UI tests were not run. Installer metadata is set to 11.10.0 for a future build.
